# 🌐 Global Wellness Guide

An AI-powered holistic wellness and personalized health recovery plan generator built with Next.js 15, React, and Tailwind CSS. Integrated with Razorpay for PDF reports and PWA support for mobile installation.

---

## ✨ Features

- **AI-Powered Symptom Analysis:** Multi-language symptom input to generate tailored health recommendations.
- **PWA Ready:** Single-click App Installation on Mobile & Desktop.
- **Razorpay Payment Integration:** Seamless PDF downloads for ₹150 INR.
- **SEO & Social Optimization:** Complete OpenGraph, Twitter Cards, and JSON-LD Structured Data for high Google ranking.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS, Shadcn UI
- **Payment Gateway:** Razorpay SDK
- **Deployment:** Vercel
